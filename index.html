Comment tester l'extension avec cette page

  1. Ouvrez Documenter dans un onglet et générez un rapport de consultation.
  2. Revenez sur cette page, ouvrez le panneau de l'extension et lancez la configuration.
  3. Pour chaque section proposée, cliquez le champ correspondant ci-dessous. Une seule fois : les champs sont mémorisés.
  4. Cliquez Remplir le dossier, puis vérifiez chaque champ. Annuler le remplissage doit tout remettre en état.

Si rien ne se passe : vérifiez que l'extension est bien installée et activée, puis rechargez cette page — une extension ne s'attache à un onglet qu'au chargement. Si vous avez enregistré cette page sur votre ordinateur, rouvrez-la depuis son adresse web : l'extension ne reconnaît pas les fichiers locaux.

Aucune donnée n'est envoyée nulle part : cette page ne contient aucun script réseau, et le patient est inventé. Écrivez ce que vous voulez dedans.

Limites connues — inutile de les signaler

  • Deux champs au même libellé (carte 8) : l'extension refuse au lieu de choisir. C'est volontaire — remplir le mauvais champ serait pire.
